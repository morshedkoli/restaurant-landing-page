# 🍽️ Gourmet Restaurant — Interactive Showcase & Menu Portal

An elegant, mobile-responsive restaurant landing page and digital menu showcase featuring interactive maps via **Leaflet.js**, smooth parallax scrolling, and an online table reservation module.

---

## 🌟 Features

- **📖 Digital Menu**: Beautifully categorized food and beverage menus with high-resolution imagery and pricing.
- **🗺️ Interactive Location Map**: Integrated Leaflet.js map with custom GPS markers and turn-by-turn directions.
- **📅 Table Reservation Form**: Intuitive reservation booking form with date and time selection.
- **📱 Fluid Responsiveness**: Handcrafted Vanilla CSS layout optimized across smartphones, tablets, and desktops.

---

## 🚀 Launch Locally

Simply open `index.html` in any web browser or serve with:
```bash
npx serve .
```
